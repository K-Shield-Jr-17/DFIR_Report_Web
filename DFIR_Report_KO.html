1. 최종 결론

PowerShell 실행과 다운로드·조건부 실행 명령 처리는 확인됩니다. a.exe 자체 실행 성공은 제공 EVTX만으로 확인되지 않습니다. 서비스 시작 명령, 파일 서버 계정의 피해 PC 대상 인증, employee의 로컬 계정 조회를 확인했습니다. Sliver 비콘·서비스 경로 악용 성공·LSASS 덤프·피해 PC에서 파일 서버로의 원격 실행 성공은 입증되지 않았습니다.

현재 제공된 EVTX 5개를 다시 대조하고, 마지막 시간 통일 경계 이후 393건 전부의 EventData·이름 없는 Data·UserData·Binary 존재 및 프로세스/계정 필드를 점검했습니다. VMware 직접 관련 66건은 환경 구성으로 분류해 사건 본문에서 제외했습니다. 남은 327건의 검토 사유와 XML은 전체 검토 대장에서 확인할 수 있습니다.

“분석 완료”는 제공된 자료와 지정한 범위의 검토가 끝났다는 뜻입니다. “a.exe 실행 미확인”은 검토를 남겼다는 뜻이 아니라, 이 자료에 실행 성공을 판정할 독립 증거가 없다는 뜻입니다.

2. 분석 범위와 시간 기준

사용자 지침에 따라 시각 변경은 시나리오 환경의 시간 통일로 취급합니다. 마지막 큰 시간 변경 묶음인 Security 4616 R4256 / System Kernel-General R1428을 경계로 삼고, 같은 초(17:54:47 UTC)에 기록된 연관 이벤트를 함께 포함했습니다. security.evtx · 4616 / R4256 / system.evtx · 1 / R1428

3.1 PowerShell 다운로드 세션과 a.exe

powershell_classic.evtx · 400 / R49는 엔진 Available 및 PowerShell.exe -nop -c ...를 기록합니다. powershell_operational.evtx · 4104 / R75는 같은 다운로드·조건부 실행 코드와 PID 8932, SID S-1-5-21-1291778260-3289171352-1194275199-1107을 기록합니다. security.evtx · 4624 / R4181의 TargetUserSid와 같고 사용자명은 CORP\employee입니다.
